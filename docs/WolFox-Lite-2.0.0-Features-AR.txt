مميزات ومتطلبات WolFox Lite 2.0.0
=================================

الهدف
-----
توثيق مميزات نسخة WolFox Lite 2.0.0 وتجهيز إصدار قابل للبناء والتوزيع.

المميزات الأساسية
-----------------
- نسخة Lite خفيفة مخصصة لتزييف الموقع.
- حفظ المواقع المفضلة وإدارتها.
- جدولة المواقع والتنقلات.
- قسم إعدادات مستقل ومنظم.
- واجهة إدخال وتفعيل الكود.
- حفظ بيانات التفعيل والإعدادات والمفضلة عند التحديث.
- الاتصال بلوحة التفعيل: https://gps.p3nd.fun/api/v1
- قراءة مفتاح المشروع من GitHub Secret باسم WOLFOX_PROJECT_KEY.
- عدم تضمين المفتاح داخل السورس أو سجلات البناء.
- دعم arm64 وأجهزة iOS المحددة في إعدادات المشروع.

خريطة المدارس والمساجد
----------------------
- قسم خريطة مستقل داخل نسخة Lite.
- عرض مدارس المملكة برمز واضح: مدرسة 🏫.
- عرض مساجد المملكة برمز واضح: مسجد 🕌.
- إظهار اسم ونوع المعلم عند تحديده.
- حركة خفيفة لعلامة المدرسة لتمييزها.
- دعم الخريطة العادية والقمر الصناعي والهجين.
- ظهور المعالم تدريجيًا حسب مستوى التكبير.
- تحميل المعالم ضمن الجزء الظاهر فقط لتحسين الأداء.
- تجميع العلامات عند وجود عدد كبير منها.
- تقليل ازدحام علامات المساجد حتى مستوى تكبير مناسب.
- استخدام بيانات OpenStreetMap للمدارس والمساجد المسجلة.

البحث والاستجابة
----------------
- البحث باستخدام Apple Maps.
- استخدام Geocoder كخيار احتياطي.
- استخدام OpenStreetMap كمصدر إضافي.
- دمج النتائج وإظهار العنوان بوضوح.
- الانتقال إلى الموقع المحدد على الخريطة.
- استمرار البحث عند تعذر أحد المصادر.

ملفات البناء المطلوبة
---------------------
- DEB Rootful.
- DEB Rootless.
- ملف DYLIB مستقل.
- حزمة Deploy مضغوطة.
- SHA256SUMS.txt للتحقق من سلامة الملفات.
- BUILD_INFO.txt بمعلومات الإصدار ومرجع البناء الصحيح.
- السورس المطابق للملفات المبنية.

ضوابط الإصدار النهائي
---------------------
- اسم المنتج: WolFox Lite.
- الإصدار: 2.0.0.
- معرّف مستقل لنسخة Lite وعدم بنائها بهوية Full.
- توحيد Architecture داخل بيانات الحزم.
- منع إعدادات CI-UNCONFIGURED و invalid.example.
- عدم تغيير أو حذف مفاتيح الإصدارات القديمة.
- عدم التأثير على التطبيقات القديمة أو بيانات المستخدم.
- نجاح اختبارات Linux وفصل Lite وأمان الترخيص والتخزين.
- فحص DEB وDYLIB وبصمات SHA-256 قبل اعتماد الإصدار.
