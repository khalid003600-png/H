# هدف الفرع: الواجهة الرئيسية K7GPS

هذا الفرع مخصص لمطابقة شاشة K7GPS الرئيسية الظاهرة في الصور.

## العناصر المعتمدة
- شريط علوي باسم K7GPS مع زر المعلومات والإغلاق.
- حقل بحث للإحداثيات أو العنوان.
- أزرار: المحفوظات، حفظ، استعادة.
- بطاقة خريطة كبيرة مع زر تكبير.
- تبديل عادي / قمر صناعي.
- زر موقعي.
- مفتاح تفعيل تغيير الموقع.
- أزرار: مسار، عشوائي، الجدولة.
- قسم صورة بديلة مع عكس / رفع / حذف.
- أقسام البلوتوث والواي فاي.
- شريط الهوية: نسخ / تعبئة / هوية / استعادة.
- أزرار أسفل الصفحة: إيقاف الكل / إخفاء الأداة / تخصيص.

القاعدة المصدرية مأخوذة من feature/k7gps-ui-source مع الحفاظ على K7GPSStore وK7GPSEngine.
