# سورس واجهة K7GPS

هذا الفرع يحتوي بداية سورس مستقلة لواجهة K7GPS مستوحاة من الصور المرفوعة في المحادثة.

## الملفات
- `K7GPSViewController.h` تعريف الواجهة.
- `K7GPSViewController.m` تنفيذ الواجهة والأزرار الأساسية.

## الموجود حالياً
- عنوان K7GPS.
- حقل البحث.
- المحفوظات / حفظ / استعادة.
- بطاقة الخريطة.
- عادي / قمر صناعي.
- موقعي.
- تفعيل تغيير الموقع.
- مسار / عشوائي / الجدولة.
- صورة بديلة مع عكس / رفع / حذف.
- البلوتوث / الواي فاي.
- إيقاف الكل / إخفاء الأداة / تخصيص.
- خيارات الإظهار بعد الإخفاء: هز الجهاز، 3، 5، 7 ضغطات، ضغط مطوّل.

## ملاحظة
هذا سورس واجهة قابلة للتطوير، وتم فصلها في فرع مستقل حتى لا يتم العبث بالفروع الحالية.
