# WolFox 1.8.2-Full

المصدر الكامل لأداة WolFox مع واجهة اختيار الصورة المباشرة من الكاميرا، وبناء آلي لحزمتي Rootful وRootless.

- الهدف: iOS 15.8–26.5 (توافق مصدر؛ البناء باستخدام iPhoneOS 16.5 SDK)
- المعمارية: `arm64`
- المخرجات: `WolFox.dylib` وحزمتا DEB موقعتان بـ `ldid`
- اختيار الصورة: أيقونة عائمة تفتح `PHPicker` مباشرة وتفعّل الصورة تلقائياً
- العرض: الصورة الطولية كاملة بأسلوب Aspect Fit ومن دون ظهور أدوات WolFox في الصورة الملتقطة

للتفاصيل العربية الكاملة راجع [README_AR.md](README_AR.md).

## البناء على GitHub

يفعّل أي دفع إلى `main` مسار **Build WolFox 1.8.2** تلقائياً. ويمكن تشغيله يدوياً من تبويب Actions مع إدخال Bundle IDs مفصولة بفواصل. بعد النجاح ستظهر الحزم في قسم Artifacts الخاص بالتشغيل.

## البناء على Ubuntu

```bash
WOLFOX_TARGET_BUNDLE_IDS="com.example.app" ./wolfox_setup_build.sh
```

يجب تحديد التطبيقات المصرّح لك باختبارها فقط؛ لا ينشئ مسار البناء حقناً عاماً.
