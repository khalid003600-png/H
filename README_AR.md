# WolFox Full 1.8.2 — Dark Blue UI

WolFox لوحة عربية RTL لأدوات الموقع والاختبار داخل تطبيقات iOS المصرّح بها. تشمل هذه النسخة إدارة الموقع والمسارات، المعرّفات، Bluetooth، الكاميرا الافتراضية، النسخ الاحتياطي والتشخيص، وإعدادات وصول متكاملة.

## المتطلبات

- Ubuntu 20.04 أو 22.04 أو 24.04 للبناء.
- Theos مع iPhoneOS 16.5 SDK.
- Clang وLLD وdpkg و`ldid`.
- مفتاح مشروع في المتغير `WOLFOX_PROJECT_KEY`.
- Bundle ID واحد أو أكثر لتطبيقات مصرح لك باختبارها.
- جهاز Jailbreak مناسب لحزمة Rootful أو Rootless للاختبار النهائي.

مسار البناء المستقر ينتج `arm64` فقط. لا تُضاف شريحة `arm64e` مستقلة قبل توفر Toolchain موثوقة ونجاح الاختبار على جهاز فعلي.

## الميزات

### الموقع والمسارات

- تحديد موقع من الخريطة أو الاسم أو العنوان أو الإحداثيات أو رابط المشاركة.
- إظهار الموقع الحقيقي والوهمي بألوان منفصلة.
- حفظ المفضلة وتعديل الاسم والإحداثيات.
- سجل لآخر 50 موقعًا مع إعادة التفعيل والمسح المؤكد.
- ملفات مواقع سريعة تحفظ الإحداثية والسرعة والفاصل الزمني وحالة الحركة.
- مسارات محفوظة مع معاينة خطية، سرعة وفاصل زمني، واستعادة آمنة بعد الإيقاف.
- توليد نقاط طريق متكيّفة مع طول المسار.

### الواجهة والتحكم

- واجهة Dark Blue عالية التباين وخمسة أقسام: GPS، المعرّفات، Bluetooth، الكاميرا والإعدادات.
- إخفاء الواجهة عند البدء وإظهارها بعدد قابل للاختيار من ضغطات الصوت.
- علامة حالة عائمة قابلة للتحريك وتعديل الحجم والشفافية والإخفاء.
- لوحة تحكم سريعة لبدء الموقع أو إيقافه وفتح الخريطة وتطبيق مفضلة.
- شريط لوحة مفاتيح لاختصارات اللصق والنسخ والإدخال والبحث والرجوع والطي.

### المعرّفات وBluetooth

- UUID موحد لمسارات IDFA وIDFV وWebView.
- التحقق من UUID وإزالة التكرار وتقييد عدد السجلات.
- حفظ ملفات Bluetooth والتحقق من UUID وتقييد RSSI.
- إيقاف Bluetooth تلقائيًا إذا فُقد الملف النشط أو حُذف.

### الكاميرا الافتراضية

- اختيار صورة واحدة باستخدام PHPicker وتشغيلها مباشرة.
- دعم المعاينة والبث الثابت وصيغ BGRA وNV12 ومسار AVCapturePhoto.
- حفظ آخر صورة اختياريًا أو مسحها، وتعطيل البث إذا اختفى الملف.
- إخفاء أدوات WolFox قبل الالتقاط حتى لا تظهر في الناتج.

### البيانات والوصول

- تصدير ومشاركة نسخة JSON واستيرادها من الحافظة.
- مسح انتقائي للمفضلة أو السجل أو الملفات مع تأكيد.
- تقرير تشخيص منزوع المفاتيح والأسرار.
- نص ديناميكي يتبع حجم خط النظام مع حد يمنع انهيار التخطيط.
- خيار تقليل الحركة مع احترام إعداد iOS، وهوامش محسنة للشاشات الصغيرة.
- تسميات VoiceOver لأزرار التحكم الأساسية.

## البناء المحلي

```bash
chmod +x ./*.sh tools/*.sh
WOLFOX_TARGET_BUNDLE_IDS="com.example.authorized-app" \
WOLFOX_PROJECT_KEY="set-in-your-shell" \
./wolfox_setup_build.sh
```

لا تكتب قيمة المفتاح في ملف أو Commit. سكربت البناء ينشئ Header مؤقتًا داخل مجلد البناء بصلاحيات مقيدة، ثم ينتج حزمتي Rootful وRootless الموقعتين.

## التحقق

```bash
./run_all_linux_tests.sh
./verify_release_artifacts.sh
```

التحقق النهائي يفحص:

- Mach-O arm64.
- حقل `iphoneos-arm64` في الحزمتين.
- مسار MobileSubstrate الصحيح لكل من Rootful وRootless.
- تطابق `WolFox.dylib` داخل الحزمتين مع الملف المبني.
- إنشاء `SHA256SUMS` و`BUILD_MANIFEST.txt`.

## التثبيت

1. اختر حزمة Rootful أو Rootless المطابقة لبيئة Jailbreak.
2. ثبّت DEB بمدير الحزم الموثوق على جهاز الاختبار.
3. نفّذ Respring إن لم يحدث تلقائيًا.
4. افتح التطبيق المستهدف وتحقق من ظهور شاشة التفعيل.
5. نفّذ [قائمة اختبار الجهاز](DEVICE_TEST_CHECKLIST.md) قبل اعتماد الإصدار.

## القيود

- نجاح CI لا يثبت عمل الهوكات على كل إصدار iOS أو كل Jailbreak.
- توافق المصدر حتى iOS 26.5 ليس بديلًا عن اختبار جهاز فعلي.
- لا يوفر المشروع حقنًا عامًا أو آلية لتجاوز اكتشاف Jailbreak.
- استخدم الأداة فقط ضمن تطبيقات وأجهزة تملك حق اختبارها.
