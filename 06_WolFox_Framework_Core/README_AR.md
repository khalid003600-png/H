# 06 WolFox Framework / Core

هذا هو المسار السادس المستقل للبنية المشتركة. ليس إصداراً سادساً للمستخدم، ولا يغيّر المنتجات الخمسة الحالية.

## الهدف

تجميع المكوّنات المشتركة تدريجياً داخل `WolFoxCore.dylib` بعد نجاح الإصدارات المستقلة، مع إبقاء كل إصدار قابلاً للبناء منفرداً أثناء مرحلة الانتقال.

## المرحلة الأولى

المكوّنات المشتركة المرشحة داخل الـCore:

- عميل الترخيص والاتصال بـ License Hub.
- حالة وإعدادات التزييف المشتركة.
- CoreLocation hooks المشتركة.
- الثيم والمساعدات العامة والـlogging الآمن.
- Compatibility/API guards.

## التثبيت المقترح

- Rootful: `/usr/lib/WolFox/WolFoxCore.dylib`
- Rootless: `/var/jb/usr/lib/WolFox/WolFoxCore.dylib`

الإصدارات الخمسة لا تعتمد Runtime على هذا الملف حتى يتم الانتهاء من مرحلة الدمج والاختبار لكل إصدار على حدة.
