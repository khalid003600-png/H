# WolFox WhatsApp Location

نسخة مستقلة خفيفة مخصصة لتزييف الموقع داخل WhatsApp فقط.

## الواجهة
- شاشة تفعيل بالكود أولاً عبر WFLicenseClient / WFActivationViewController.
- بعد التفعيل: خانة بحث واحدة + زر لصق داخل الشريط.
- خريطة كبيرة.
- زر تشغيل/إيقاف التزييف.
- زر الإعدادات أسفل زر التشغيل.
- دعم VoiceOver عبر accessibilityLabel بدون محاولة تعطيل VoiceOver من داخل التطبيق.

## البحث
- اسم مكان أو عنوان مختصر عبر MKLocalSearch.
- إحداثيات مباشرة مثل: 24.7136,46.6753
- روابط خرائط التي تحتوي q/query/ll أو إحداثيات ضمن النص.

## الاستهداف
هذه النسخة يجب أن تُبنى باستهداف Bundle ID الخاص بواتساب فقط، مع إعادة استخدام نفس هوكات CoreLocation ونظام الترخيص من المشروع الأساسي.
